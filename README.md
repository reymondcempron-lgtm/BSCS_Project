## Description
An interactive 3D model of a modern dream house built using Python and VPython. Features exterior architectural design, second-floor open living terraces, garden lounge, swimming pool with underwater illumination, carport, pet house, animated stylized sky with sun, drifting clouds, and flying birds.

---

## Requirements
- Python 3.8+
- VPython (`pip install vpython`)

---

## How to Run
```bash
python dreamhouse_3d.py
```

---

## Controls
### Interactive Buttons
- **Exterior:** Reference front elevation view
- **3D view:** Isometric aerial perspective
- **Pool:** Swimming pool & garden view
- **Garden:** Outdoor lounge & relaxation area
- **Carport:** Parking bay & sports car view
- **Terrace:** Right sunset cocktail lounge
- **Top view:** Overhead plan view
- **Day / Night:** Toggle between daylight and illuminated night mode
- **Gate:** Open / close front entrance gate
- **Car gate:** Open / close driveway vehicle gates

### Keyboard Shortcuts
- `[L]` - Toggle Day / Night illumination
- `[G]` - Toggle Pedestrian Gate
- `[C]` - Toggle Driveway Car Gate
- `[1]` to `[9]` - Camera viewpoints
- Mouse Drag - Orbit & rotate 3D scene
- Mouse Scroll - Zoom in & out
