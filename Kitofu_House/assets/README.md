# Asset origins

All architecture, furniture, plants, vehicles, dog, butterfly and signage are
procedurally generated in the Python source. No external images, textures,
fonts, downloaded models or paid assets are required.

The available attachment was the written project brief only. Concept 03 and the
dog photograph were not present, so the design follows the brief's descriptions,
not a verified visual match to those missing images. No classmate source was supplied.

The sport motorcycle is a simplified white/blue/red M1000RR-inspired interpretation,
without logos, exact manufacturer fidelity or official affiliation. Other models
are original stylized interpretations. VPython is an external open-source dependency;
its package includes its own browser runtime and licenses.
