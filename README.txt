DREAM HOUSE WITH BACKYARD POOL - THREE.JS PROJECT

YOUR SELECTED DESIGN:
  FRONT: Option A two-storey modern tropical luxury exterior, landscaped garden, front carport; NO pool in front.
  BACK:  Option C resort-style private swimming pool, waterfall, timber deck, furnished lounge, glass balcony.

OPEN IN VS CODE (SAME AS YOUR PREVIOUS PROJECT):
1. Download and extract the ZIP.
2. VS Code > File > Open Folder > dream-house-with-backyard-pool.
3. Right-click index.html > Open with Live Server (or click Go Live at bottom right).
4. Browser opens the 3D house.

ALTERNATIVE IF LIVE SERVER DOES NOT WORK:
  Open a VS Code terminal in the project folder and run:
    python -m http.server 5500
  Then open http://localhost:5500 in Chrome.

CONTROLS:
  Left-click and drag: rotate the 3D house.
  Mouse wheel: zoom in/out.
  Right-click and drag: move view (pan).
  Front / Angle / Right / Back / Pool / Top buttons: jump to a view.
  Daytime / Dusk buttons: change scene lighting.

FILES:
  index.html - webpage/buttons
  style.css - appearance of the controls
  main.js - geometry, swimming pool, furniture, garden, lighting, and camera controls

REQUIRES INTERNET to load Three.js from a CDN.
This is a detailed interactive CONCEPT MODEL and not a photorealistic architectural render or a construction blueprint.
